# Stochastic Processes Problem Set — Modeling Stock Price Movements

Simulates and compares three stochastic models of equity price behavior —
Geometric Brownian Motion, an Ornstein-Uhlenbeck mean-reverting process, and
a Merton Jump-Diffusion process — calibrated to Tesla (TSLA) historical
prices, with Monte Carlo simulation, visualization, and risk analysis.

## Data source

The **only** data source used in this project is the Kaggle dataset
[`jillanisofttech/tesla-stock-price`](https://www.kaggle.com/datasets/jillanisofttech/tesla-stock-price).
It was downloaded once via `kagglehub` and committed to
[`data/kaggle_raw/`](data/kaggle_raw/) for reproducibility, so the notebook
runs entirely offline — no API key, and no other ticker or provider, is used
anywhere in this project. Of the two files in the dataset,
`Tasla_Stock_Updated_V2.csv` is used: split-adjusted daily OHLCV from
2015-01-02 through 2024-01-16 (2,358 trading days after cleaning).

## Deliverables

| File | Description |
|---|---|

## How to run

```bash
python -m venv .venv
.venv/Scripts/activate          # Windows
pip install -r requirements.txt

# Run the analysis notebook end-to-end (no internet access needed)
jupyter nbconvert --to notebook --execute --inplace Stochastic_Price_Simulation.ipynb
# (or open it in Jupyter/VS Code and Run All)

# Regenerate the Word report from the notebook's saved figures/tables
python report/generate_report.py
```

To re-download the raw dataset from Kaggle instead of using the committed
copy in `data/kaggle_raw/`, run:

```python
import kagglehub
path = kagglehub.dataset_download("jillanisofttech/tesla-stock-price")
```
